# Приёмка единого аудита

Проверка привязана к опубликованной версии Markdown организаторов. Она сверяет SHA-256, каждую цитату с её строками и независимые вопросы для групп, где требуется несколько решений. [Исходный документ](https://github.com/BCC-HUB/ai-requirements-validator-task/blob/928c1aa364265426105b69ba7a3444eac11b22db/docs/requirements.md)

```sh
python -m tools.check_official_case requirements.md
python -m tools.check_expanded_acceptance requirements.md
python run.py requirements.md reports/review-ru.md
python run.py requirements.md reports/review.json
python -m tools.check_expanded_acceptance requirements.md --report reports/review.json
```

В браузере на 390 и 1440 px проверены загрузка примера, переключение темы и языка, уточнение GET → POST, сравнение и скачивание Word. При отключённом провайдере результат явно помечен как выполненный правилами. В тесте подписанного повторного прогона три соседних с правкой блока были перепроверены индивидуально, три неизменённых использованы повторно, все шесть были проверены в составе набора.

Проверка схем сравнивает читаемые подписи. Возможное визуальное расхождение остаётся с низкой уверенностью до сверки. Сканированным PDF нужен текстовый слой. Проверка общедоступных ссылок ограничена восемью адресами за один прогон, HTTP HEAD и пятью секундами. Редирект и ответ 405 требуют ручной проверки.

На `04ae92f` модель Gemini 3.5 Flash Lite подтвердила 15 из 15 тем и 110 цитат. Синтетический ошибочный пример дал 13 замечаний, включая повтор расчётов и пустой ячейки. В исходном чистом примере модель указала на границу 30-го дня и предложила разделить приёмочную строку. Границы явно заданы в следующей версии примера. Повторы расчёта, диапазона и пустого результата покрыты отдельной регрессией.

На `0d9ea51` повторный прогон Gemini дал 15/15 по официальному ТЗ и 6/6 по QR-кейсу. В исправленном QR одна строка перехода совпала со схемой. Два замечания остались вне контроля схем. В браузере на 390 и 1440 px пройдены ИИ-аудит, правка GET → POST, перепроверка с повторным использованием оценок, Word и отмена правки. В чистом синтетическом примере модель задала вопросы о канале доступа и истечении срока. В следующей версии примера явно указан внутренний экран и сообщение при истечении срока.

На `be05e96` реальный прогон организаторского ТЗ занял 19,2 с, подтвердил 15/15 групп и 104 дословные цитаты. У семи измеренных текстовых элементов главной страницы контраст составил не менее 5,33:1 в обеих темах. Анонимный HEAD подтвердил доступность публичной ссылки IANA. В ошибочном примере обнаружены шесть контрольных дефектов и два перефразированных замечания, которые добавлены в регрессию. В согласованном примере вопросы о дате по умолчанию и пустом отчёте сделали условия приёмки точнее.
