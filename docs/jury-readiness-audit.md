# SanA1 нұсқасын тексеру

## Әр өзгерістен кейінгі бағалау

Жарыстың төрт критерийінің әрқайсысы қорытынды балдың 25%-ын құрайды. Тексергенде Git коммитін, файлдың SHA-256 хэшін және режимді жазыңыз. Модельдің нақты жауабын, сақталған жауапты браузерде қайта ойнатуды және кірістірілген ережелерді бөлек белгілеңіз. [Қазылар критерийлері](https://bcchubagents.mnu.kz/#judging)

| Критерий | Тексерілетін нәтиже |
| --- | --- |
| Талаптарды нақтылау | Ф-3 және Ф-4 үзінділерін ашыңыз. А және B жауаптарының қайсысы екінші push-хабарламаға рұқсат беретінін тексеріңіз. Таңдалған жауап пен өзгерген тармақты салыстырыңыз. |
| Архитектура | Таза көшірмеден README командасын орындаңыз. Есеп паспортындағы файл хэшін, агент нұсқасын және шақырылған модельдерді тексеріңіз. Жеке бағадан өтпеген талаптар саны және бүкіл жинақтың бағасы көрінуі тиіс. |
| Өнімнің сапасы мен құндылығы | Есептің дәйексөздерін түпнұсқамен салыстырыңыз. Ресми кейсті, нүктелік түзетулері бар нұсқаларды және тәуелсіз QR жұбын өткізіңіз. Табылған, өткізіп алынған және қате белгіленген жағдайларды тіркеңіз. |
| Таныстыру | Жария сайтты 390 және 1440 px өлшемдерінде ашыңыз. Құжатты жүктеп, дәлелден бастапқы жолға өтіңіз, шешімді бекітіңіз, қайта тексеріңіз және орысша Markdown есебін жүктеңіз. |

Қазылар қолданатын команда мен жүктеу сілтемелері README-де, ал бақылау тақырыптары, жол нөмірлері және қайталау командалары қабылдау құжатында берілген. [Іске қосу](../README.md) · [Қабылдау сынақтары](acceptance.md)

## Құжат тіліндегі есепті тексеру

Жария сайтқа қазақша, орысша және ағылшынша үш төлем ТЗ-сы бөлек жүктелді. Интерфейс үш сынақта да орысша қалды. `b5ccc12` серверлік нұсқасы әр құжаттың үш талабын жеке тексерді. Браузерде ашылған есеп пен жүктелген Markdown тілі әр жолы кіріс тілімен сәйкес келді. 390 және 1440 px экрандарында файл хэші, бастапқы дәйексөз, талап нөмірі және жүктеу батырмасы тексерілді. [Үш бастапқы ТЗ және сайттан жүктелген үш есеп](https://github.com/mansurkenma54/SanA1-Hackathon/releases/download/jury-2026-11-27/SanA1-KK-RU-EN.zip)

Қазақша ТЗ-да «жылдам» деген сөзге агент түбіртекті көрсетудің ең ұзақ уақытын сұрады. Сондай-ақ түбіртекті жүктеуге берілген 30 күннің басталу оқиғасын нақтылауды ұсынды. Алдыңғы `294f86c` нұсқасында қазақша аударма үзілген еді. Сол сақталған есепті жаңа нұсқамен қайта аударғанда үш талап, үш ескерту және алты дәйексөз толық сақталды. Бөлек жасалған жаңа аудит екі ескерту берді. Модельді қайта шақырғанда ескертулер саны өзгеруі мүмкін. [Тексерілген ашық код](https://github.com/mansurkenma54/SanA1-Hackathon/tree/6ad6c3a3c04a56c896af9569479354d948679f34) · [Windows және Ubuntu сынақтары](https://github.com/mansurkenma54/SanA1-Hackathon/actions/runs/46048452130)
