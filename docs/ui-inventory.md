# Инвентаризация интерфейса SanA1

Исходная версия `5f9637f`. В рабочем пространстве проверяются загрузка, чтение документа, поток событий, исправления, перепроверка и экспорт. В итоговом отчёте проверки разбираются отдельно от самой навигации.

| Область | Элементы исходного интерфейса | Решение |
| --- | --- | --- |
| Шапка | Ссылка пропуска навигации, логотип, Главная, Рабочая область, RU / KK / EN, тема | Сохранить с доступными именами и сохранением темы и языка. |
| Главная | Полный ИИ-аудит, Демо правок, инструкция | Оставить «Начать» и три коротких шага. Пример доступен из загрузки. |
| Рабочая область | Мой документ в демо, Документ, Аудит, Правки, Перепроверка, Файлы | Сохранить прямую навигацию для старых ссылок на демо и добавить состояние шагов самого аудита. |
| Компоновка | Рядом, Документ, Аудит и правки | Сохранить для широкого и узкого экрана. |
| Загрузка | Загрузить файл, скрытый выбор файла, вставка текста, перетаскивание, очистка, Попробовать демо, Загрузить пример DOCX, скачать пример | Оставить загрузку, вставку, перетаскивание и очистку. Объединить пути к примеру в «Загрузить пример». |
| Аудит | Полный ИИ-аудит, Другие проверки, Локальные правила, Пошаговая проверка, отдельный запасной запуск правил после ошибки | Оставить «Проверить». При недоступности модели показывать явно подписанный результат правил. Прежние API доступны для интеграций. |
| Документ | Документ, Редактировать текст, Оригинал PDF, скрытый выбор изображений, Добавить изображения, скачать черновик в Word или Markdown | Сохранить различные способы работы с исходником. |
| PDF | Номер страницы, Перейти, Назад/Вперёд, загрузка оригинала, повтор чтения страницы | Сохранить, показывать для PDF. |
| Восстановление | Сохранять работу в этой вкладке | Сохранить явное согласие на локальное хранение. |
| Стандарт | Структурная проверка, профиль, источники и границы проверки | Сохранить профиль и пояснение об охвате. |
| Результат | Перейти к правкам, ссылки и их статусы, требования и поиск, паспорт, проверка структуры, файлы, сравнение | Сохранить внутри единого отчёта. |
| Замечания | Фильтры по приоритету и критерию, очистка фильтров, вопросы автору, раскрытие карточек, переход в исходник, возврат к замечанию | Сохранить для проверки и исправления. |
| Правка | Закрыть, варианты ответа, выбрать фрагмент, ответ, AI-формулировка, предпросмотр, изменить или исключить фрагмент, добавить ещё фрагмент, применить очередь, ручное подтверждение | Сохранить подтверждение автора, сравнение и пакетное применение. Добавить откат. |
| Выполнение | Журнал, время, прервать ожидание, повторить | Сохранить. Завершённый журнал сворачивать. |
| Экспорт | Черновик Word/Markdown, итоговый Word/Markdown, отчёт Markdown/JSON, вопросы, отдельный экспорт старого пошагового режима в TXT/HTML | Сохранить экспорт одного отчёта и экспорт рабочей версии. Старый режим убрать из основного интерфейса. |
| Подвал | Логотип, Рабочая область, Демо, API, ТЗ хакатона | Оставить логотип, Рабочую область, API и ТЗ. Ссылку на демо убрать как дублирующий вход. |
